### ⚡ About me

I build AI products end to end: the agents, the workflows that keep them on track, and the apps people actually use them through.

- 🤖 **AI agents & agentic engineering:** multi-session agent orchestration, tool use, MCP, LLM-powered workflows
- 🛠️ **Developer tools:** I'm building [**MasterDeck**](https://masterdeck.dev), a command center for running many Claude Code sessions at once
- 📱 **Apps that ship:** years of Android (Kotlin, Compose), Flutter and web behind me, so the AI lands in a real product
- ☁️ **The plumbing:** TypeScript backends, cloud deploys, CI/CD and the glue in between
